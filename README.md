# Individual Finance Manager (Cozy Coins)

Personal finance manager: expenses, subscriptions, income bottles, living limit and reports.
Data stays local in `data/finance.db` (git-ignored).

```bash
npm install
npm run dev        # http://localhost:3000
npm run check      # lint + typecheck + tests
```

Project docs: [docs/README.md](docs/README.md). Team workflow: [AGENTS.md](AGENTS.md).
